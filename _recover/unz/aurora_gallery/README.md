# Aurora — концепт-галерея (Flutter)

Быстрая, плотная и стильная галерея с настраиваемыми темами. Это первый шаг —
рабочий каркас интерфейса на тестовых картинках. Дальше подключим реальные фото
с устройства и авто-тегирование.

## Что уже есть

- Боковая панель + тонкая шапка: максимум места под картинки.
- Три режима: «Все» (плотная сетка), «По датам», «Альбомы/папки».
- Регулятор плотности (ползунок) — размер плиток меняется вживую.
- Просмотрщик: свайпы между фото, зум, информационная панель на планшете.
- 5 тем (Sand, Charcoal, Forest, Ocean, Plum) — переключаются точками в шапке.
- Сетка на `GridView.builder` — рисуются только видимые плитки, поэтому
  интерфейс не тормозит даже на сотнях тысяч изображений.

Сейчас картинки берутся из интернета (picsum.photos) — только чтобы наполнить
демо. На реальном устройстве их заменит чтение локальных фото.

## Как получить приложение под Windows (без установки чего-либо тяжёлого)

1. Создай бесплатный аккаунт на https://github.com
2. Создай новый репозиторий (New repository), назови, например, `aurora-gallery`,
   сделай его Private, нажми Create.
3. На странице репозитория: **Add file → Upload files**, перетащи туда всё
   содержимое этой папки (включая папки `lib` и `.github`), внизу нажми
   **Commit changes**.
4. Открой вкладку **Actions** — сборка «Build Windows app» запустится сама
   (5–10 минут). Дождись зелёной галочки.
5. Зайди в завершённую сборку → блок **Artifacts** → скачай
   `aurora-gallery-windows` (это zip).
6. Распакуй zip и запусти `aurora_gallery.exe`. Готово — приложение откроется
   на ПК. (Папку нужно держать целиком: рядом с .exe лежат нужные ему файлы.)

При любом изменении кода новая сборка появляется автоматически.

> Android-сборку добавим следующим шагом — код общий, понадобится только
> заменить workflow на сборку APK.

## Структура

```
lib/
  main.dart        — запуск, переключение тем
  theme.dart       — палитры тем (добавить тему = добавить один объект)
  sample_data.dart — тестовые данные (заменим на реальные фото)
  home_page.dart   — главный экран: панель, режимы, сетки, альбомы
  viewer_page.dart — полноэкранный просмотрщик
.github/workflows/build.yml — облачная сборка APK
```
